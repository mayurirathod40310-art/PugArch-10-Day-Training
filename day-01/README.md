# Day 1 — Programming Fundamentals & Problem Solving

## Objective

Practice Python programming fundamentals, data structures, algorithms, and problem-solving through programming exercises and a practical Employee Management CLI application.

## Problem Statement

The objective of this task is to strengthen programming and problem-solving skills by solving common programming problems and building a command-line application for managing employee records.

## Exercises

Completed 15 programming problems covering:

* Strings and lists
* Dictionaries and sets
* Stack and queue
* Searching and sorting
* Recursion
* Maximum subarray sum
* Time and space complexity

## Practical Assignment — Employee Management CLI

A Python command-line application for managing employee records.

### Features

* Add Employee
* View Employees
* Update Employee
* Delete Employee
* Search Employee
* Highest Salary
* Average Salary
* Department Filter
* Input Validation

## Technology Stack

* Python
* Git
* GitHub

## Architecture

The application follows a simple command-line architecture:

```text
User
  ↓
Command-Line Menu
  ↓
Employee Management Functions
  ↓
Employee Records
```

The application accepts user input through the command line and performs the selected employee management operation.

## Installation

### Prerequisites

* Python 3.x
* Git

No external Python libraries are required for the Employee Management CLI.

## How to Run

### Employee Management Application

Navigate to the project directory:

```bash
cd employee-management
python app.py
```

### Programming Exercises

Navigate to the exercises directory:

```bash
cd exercises
python practice-problems.py
```
