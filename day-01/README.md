# Day 1 — Programming Fundamentals & Problem Solving

## Objective
Practice Python programming fundamentals, data structures, algorithms, and problem-solving.

## Exercises
Completed 15 programming problems covering:
- Strings and lists
- Dictionaries and sets
- Stack and queue
- Searching and sorting
- Recursion
- Maximum subarray sum
- Time and space complexity

## Practical Assignment — Employee Management CLI

A Python command-line application for managing employee records.

### Features
- Add Employee
- View Employees
- Update Employee
- Delete Employee
- Search Employee
- Highest Salary
- Average Salary
- Department Filter
- Input Validation
